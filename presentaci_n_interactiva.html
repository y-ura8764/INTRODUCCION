1. ¿Qué es una red?

Una red de computadores es un conjunto de equipos conectados para compartir información y recursos.

3. Topología en estrella

Todos los equipos se conectan a un punto central (el Switch).

  • Ventaja: Si rompes una conexión, los demás siguen funcionando.
  • Desventaja: Si apagas el Switch central, se cae toda la red.

👉 Interactivo: Haz clic en un cable para cortarlo. Haz clic en el Switch central para apagarlo todo.

4. ¿Qué es un Sistema Operativo (SO)?

Es el software principal que gestiona los recursos del hardware y permite la comunicación entre el usuario y la máquina. Sin él, el computador es solo piezas inertes.

Hardware Principal: El BIOS

Basic Input/Output System

  • Es el primer programa que se ejecuta cuando se enciende la computadora [74].
  • Su propósito fundamental es iniciar y probar todo el hardware del sistema para luego cargar el sistema operativo [75].
  • Actúa como una capa de abstracción, permitiendo que los programas interactúen con componentes como el teclado o el monitor [76].
